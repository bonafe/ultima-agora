Rodar a sua Ágora

Você não precisa programar. Precisa instalar um programa, copiar três comandos e passar um link para os seus amigos.

Antes de começar

O que a sua Ágora vai usar:

  • 1Um computador que fique ligado enquanto vocês usam (pode ser o seu).
  • 2Docker Desktop, gratuito para uso pessoal, em docker.com. No Linux, o Docker comum com o plugin Compose.
  • 3O código da Ágora: na página do projeto, botão verde Code → Download ZIP, e descompacte.

Para usar sozinho, neste computador

Abra um terminal dentro da pasta descompactada e rode:

docker compose up -d --build

Espere terminar (na primeira vez demora uns minutos) e abra http://localhost:8080/app.html no navegador. Para parar: docker compose down.

Para chamar outras pessoas

Descubra o endereço do seu computador na rede (algo como 192.168.2.155) e rode, trocando pelo seu:

AGORA_HOSTS=192.168.2.155 docker compose up -d --build

Depois abra no navegador (e mande para os outros) este endereço, trocando o número e o seu nome:

https://192.168.2.155:8443/app.html?sync=https://192.168.2.155:8443/sync&name=Maria

Quem entrar no mesmo espaço pelo link do espaço (o que termina em #/workspace/…) aparece ali, com presença, chat e chamada.

Na primeira vez o navegador avisa que a conexão não é confiável. É porque o certificado foi criado por você, e não por uma empresa. Escolha “Avançado” e “continuar”. Isso é preciso para a câmera e o microfone funcionarem.

Convidar com um QR code

Com a Ágora no ar, o botão 📲 Convidar, no cabeçalho, mostra um QR code e o link do espaço. Quem está ao seu lado aponta a câmera do celular e entra, já no mesmo espaço (e na mesma chamada).

Se você abriu a Ágora como localhost, o diálogo avisa: esse endereço só funciona neste computador. Troque, no campo do link, pelo número da rede (como 192.168.2.155) e o QR code acompanha.

Transcrição da fala

A transcrição roda no navegador de cada pessoa e precisa de um modelo de voz (cerca de 80 MB), baixado uma vez. Com o Python instalado, na pasta do projeto:

python3 tools/baixar_modelo_whisper.py

Falar com a Ágora

Com a transcrição funcionando, cada pessoa pode ligar o 🎙 Comandos por voz e pedir coisas falando: “Ágora, adiciona uma tabela”. Digitar na mesma barra funciona sem microfone. Veja a lista de comandos. Não é preciso instalar nada além do modelo de voz.

Um modelo de IA para entender melhor (opcional)

Por padrão a Ágora entende os comandos com regras simples, no navegador, e isso basta para começar. Se quiser experimentar um modelo de IA para as frases que as regras não pegam, você pode rodá-lo no seu servidor, o que também ajuda aparelhos que não conseguem rodá-lo sozinhos. Com o Python instalado, na pasta do projeto:

python3 tools/baixar_modelo_laya.py
AGORA_MODEL_URL=http://model:8790 docker compose --profile model up -d --build

Depois acrescente &model=remote ao endereço que você passa às pessoas (ou &model=auto, que tenta o servidor e, se não der, o navegador).

  • dicaTem uma placa de vídeo NVIDIA? Acrescente -f docker-compose.gpu.yml ao comando do Docker para usar a GPU (precisa do NVIDIA Container Toolkit).
  • dicaDá para apontar para outro serviço de IA (o gateway do Inteligência Aberta, um servidor próprio ou uma API externa). Está no guia do serviço de modelo.
  • atençãoCom remote ou auto, a frase falada (já em texto) vai ao seu servidor, que a repassa ao modelo e a esquece. Se você apontar para uma API externa, a frase vai para ela.
  • atençãoSeja realista: o modelo atual ainda acerta menos que as regras e só sugere. Ele ajuda na velocidade e no alcance, não na precisão. Entenda por quê.

Cuidados

  • atençãoEsta forma de rodar não pede senha: qualquer pessoa que alcance o endereço entra e escolhe o seu papel. Use em rede de confiança (a sua casa, a sua equipe), nunca aberta na internet.
  • atençãoPara grupos pequenos (até uns 4 a 6 na chamada). Entre redes diferentes, a chamada pode precisar de um servidor de apoio (TURN).
  • dicaOs dados ficam no seu computador, no volume agora-data do Docker.
